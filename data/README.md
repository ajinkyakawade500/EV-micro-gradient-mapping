# Proposed road-segment data contract

[example_segment.json](example_segment.json) is an **invented schema illustration**. It has no real location, OSM edge, measured uncertainty or calibrated rolling coefficient. It is separate from the profiles generated by the numerical experiment. This document defines a proposed contract; it is not a Valhalla API or an implemented ingestion service.

## Units and meaning

| Field | Meaning and validation rule |
|---|---|
| schema_version | Version of this proposed record format, independent of the paper version |
| evidence_status | Distinguish synthetic examples, unvalidated estimates and independently evaluated observations |
| segment_id | Internal record identity; does not claim a stable identity in an external router |
| coordinate_reference | Horizontal reference, vertical datum, chainage definition and travel direction |
| horizontal_length_m | Positive length along the plan-view path, not the three-dimensional road length |
| graph_binding | Null in this example; future records need graph snapshot digest, directed edge association, source geometry/version, and matching confidence |
| profile.samples | At least two finite coordinates; strictly increasing x from zero to horizontal_length_m |
| z_sigma_m | If present, a calibrated one-standard-deviation height uncertainty; null means unavailable, not zero |
| spatial_covariance_reference | Reference to a correlation/covariance model; dense samples must not be assumed independent |
| crossfall_deg | Future road-plane crossfall under a documented left/right sign convention; null here |
| surface_class_confidence | Future calibrated class confidence; not a resistance-error bound |
| resistance_prediction | Conditional numerical coefficient, interval definition and tyre/vehicle/calibration context; all null until calibrated |
| observations | Time coverage and independent passes, rather than raw sample count alone |
| provenance | Measurement/calibration references, method and quality flags |

The three example profile intervals have grades of 5%, 10% and 3%, obtained from 100 × change in height / horizontal distance. Do not interpret these as degrees. Along-road length is obtained from the hypotenuse of each interval.

For reverse traversal, reverse the sample sequence and transform chainage to x' = L − x. Grade signs then reverse. A bank angle needs a separately declared directional convention.

## Observation lifecycle

Retain an immutable record of the original observations and calibration. Publish derived profiles with processing/model versions and uncertainty status. Associate every map match with the exact graph build. Rematch when geometry or graph structure changes rather than trusting an old bare edge ID.

Separate slowly changing geometry from time-dependent wetness/weather and vehicle-conditioned predictions. Define an application-specific freshness policy after studying how quickly each quantity changes. No universal validity period is assumed here.

Store missing values explicitly. A missing calibrated coefficient must not silently become 0.0 or a hard-coded local estimate. Downstream software may use a declared fallback model, but must record that choice.

Any future OSM-derived or other externally sourced dataset retains its own licensing terms. This synthetic example contains no external geographic data.
